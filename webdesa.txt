1. LATAR BELAKANG
Tim KKN Universitas Diponegoro melaksanakan program KKN di Desa Sumberagung, Kecamatan Weleri, Kabupaten Kendal.

Pada tahap awal, website direncanakan sebagai media untuk menampilkan hasil pendataan desa, khususnya data UMKM dan data kesehatan.

Namun selama pelaksanaan KKN terdapat beberapa perubahan kondisi:

Pendataan UMKM tidak berhasil mencakup seluruh UMKM desa, sehingga data yang tersedia merupakan data UMKM yang berhasil ditemui/berpartisipasi dalam program pendampingan KKN.
Data kesehatan yang tersedia merupakan hasil kegiatan/skrining program kesehatan KKN, bukan data kesehatan seluruh masyarakat desa.
Tim KKN tidak memperoleh akses untuk mengelola website resmi Pemerintah Desa Sumberagung.
Website akhirnya dikembangkan sebagai website mandiri, bukan website resmi pemerintah desa.
Website diharapkan tetap memiliki manfaat setelah periode KKN berakhir dan tidak hanya menjadi dokumentasi kegiatan mahasiswa.
Berdasarkan kondisi tersebut, konsep website diarahkan dari "dashboard data desa" menjadi:

Portal informasi, potensi, dokumentasi, dan pemberdayaan Desa Sumberagung.

Website tidak dimaksudkan untuk menggantikan website resmi Pemerintah Desa dan tidak boleh memberikan kesan bahwa website merupakan kanal administratif resmi pemerintah desa.

3. TUJUAN WEBSITE
Tujuan utama:

Menjadi ruang digital yang membantu masyarakat dan pengunjung mengenal Desa Sumberagung melalui informasi mengenai profil, potensi, UMKM, kegiatan, edukasi, dan dokumentasi pemberdayaan masyarakat.

Tujuan khusus:

Memperkenalkan Desa Sumberagung kepada masyarakat yang lebih luas.
Menampilkan potensi desa secara menarik dan informatif.
Mempromosikan UMKM yang berpartisipasi dalam program pendampingan KKN.
Mengarsipkan hasil program pemberdayaan masyarakat.
Menyediakan artikel dan materi edukasi yang dapat diakses kembali.
Menyediakan dokumentasi kegiatan dan potensi desa.
Menjadi wadah digital yang masih dapat dikembangkan setelah KKN selesai.

mengarsipkan informasi dan dokumentasi.

14. HALAMAN INSIGHT KESEHATAN
Tujuan
Menampilkan hasil kegiatan Posyandu/skrining kesehatan sebagai insight dari program KKN.

Fokus
Program Sosial Kemasyarakatan/Saintek berfokus pada kegiatan kesehatan, termasuk Posyandu Lansia.

Yang dapat ditampilkan
Jika data tersedia:

jumlah peserta,
rentang usia,
tekanan darah,
gula darah,
kolesterol,
asam urat,
indikator lain yang memang diperiksa.
Gunakan data agregat.

JANGAN menampilkan data pribadi peserta.

Jangan menampilkan:

nama,
NIK,
nomor telepon,
alamat lengkap,
identitas individu,
rekam medis individu.

Contoh Insight
Jika data memang mendukung:

"Berdasarkan hasil skrining peserta Posyandu Lansia Dusun [X] pada [tanggal], sebagian besar peserta yang mengikuti pemeriksaan menunjukkan kadar gula darah di atas rentang yang digunakan sebagai acuan pemeriksaan."

Jangan menulis:

"Mayoritas lansia Desa Sumberagung memiliki gula darah tinggi."

karena data kegiatan tidak otomatis merepresentasikan seluruh lansia desa.


Disclaimer wajib
Data pada halaman ini merupakan ringkasan hasil kegiatan/skrining peserta program dan tidak merepresentasikan kondisi kesehatan seluruh masyarakat Desa Sumberagung. Informasi ditampilkan untuk tujuan dokumentasi dan edukasi, bukan sebagai diagnosis medis.

Data UMKM harus diperlakukan sebagai:

database seluruh UMKM desa.

29. DATA KESEHATAN — ATURAN PENTING
Data kesehatan harus:

anonim,
tidak mengidentifikasi individu,
memiliki konteks tanggal/kegiatan,
memiliki jumlah peserta,
memiliki disclaimer.
Data tidak boleh diposisikan sebagai statistik kesehatan resmi desa kecuali terdapat sumber resmi dan izin yang sesuai.

35. KEBUTUHAN UX
Website harus:

mobile friendly,
ringan,
mudah dinavigasi,
tidak terlalu banyak teks pada halaman awal,
menggunakan visual berkualitas,
memiliki CTA yang jelas,
memiliki konsistensi desain,
memiliki loading yang wajar,
mudah digunakan oleh pengguna non-teknis.
Prioritas perangkat:

Smartphone
Laptop/Desktop
Tablet

36. PRINSIP DESAIN
Kesan yang diinginkan:

modern,
hangat,
lokal,
informatif,
tidak terlalu formal,
tidak seperti portal pemerintahan yang kaku,
tetap profesional.
Website harus menonjolkan:

fotografi,
cerita,
manusia,
produk,
potensi,
kegiatan.

38. SEO DASAR
Minimal:

title setiap halaman,
meta description,
heading yang terstruktur,
alt text gambar,
URL yang readable,
sitemap,
favicon,
Open Graph image,
robots.txt.
Target pencarian yang relevan misalnya:

Desa Sumberagung Weleri
Sumberagung Kendal
UMKM Sumberagung

Kegiatan Desa Sumberagung

39. PERFORMANCE
Perhatikan:

kompresi gambar,
lazy loading,
ukuran video,
caching,
jumlah JavaScript,
ukuran CSS,
penggunaan CDN jika diperlukan.
Video sebaiknya tidak langsung di-host sebagai file besar jika hosting terbatas. Embed dari platform video dapat dipertimbangkan.


40. SECURITY
Minimal:

admin authentication,
password hashing,
CSRF protection,
validasi upload,
pembatasan tipe file,
pembatasan ukuran file,
environment variables untuk secret,
jangan menyimpan credential di repository.

41. PRIVACY

NIK,

informasi sensitif lainnya.
Semua konten yang menampilkan individu harus mempertimbangkan izin publikasi, terutama foto anak dan data kesehatan.


42. SUSTAINABILITY
Sustainability merupakan requirement utama.

Website harus tetap berguna walaupun:

KKN selesai,
mahasiswa tidak lagi berada di desa,
tidak ada pembaruan setiap hari.
Oleh karena itu:

Konten evergreen
profil,
sejarah,
potensi,
video profil,
edukasi,
katalog UMKM.
Konten yang dapat diperbarui
artikel,
galeri,
kegiatan,
UMKM,
program.
Konten yang tidak dijadikan inti
dashboard real-time,
data kesehatan real-time,
statistik yang membutuhkan input rutin.

46. MINIMUM ACCEPTANCE CRITERIA
Website dianggap siap digunakan jika:

Produk
semua halaman MVP tersedia,
navigasi berfungsi,
informasi utama tersedia,
konten tidak kosong.
UX

desktop responsive,
navigasi jelas,
tidak ada broken link.
Data
data UMKM memiliki konteks,
data kesehatan memiliki disclaimer,
data desa telah divalidasi,
data pribadi tidak terekspos.
Admin

upload file berfungsi,
artikel dapat dipublikasikan.
Technical

HTTPS aktif,
tidak ada error kritis,
database dapat di-backup.
Handover
tersedia dokumentasi,
tersedia credential yang diserahkan melalui cara aman,
tersedia panduan pengelolaan.
